# API webservice tutorial

## HTTP method meanings

- `GET` - Retrieve data from the server. It should not have any side effects on the server.
- `POST` - Create a new resource on the server.
- `PUT` - Update an existing resource on the server. We need to send the full representation of the resource to update it.
- `PATCH` - Update an existing resource on the server. We only need to send partial representation of the resource to update it.
- `DELETE` - Delete a resource from the server.
